# Pi Black

Claude Code wire compatibility for Pi.

This unofficial release applies the repository's patch series to the immutable Pi commit recorded in `config/pi.env` and builds Pi's six supported standalone targets.

Assets include:

- macOS arm64 and x64 archives;
- Linux arm64 and x64 archives;
- Windows arm64 and x64 archives;
- the exact `git am` patch;
- pinned source/build metadata;
- SHA-256 checksums and generated provenance.

This project is unofficial and is not affiliated with or endorsed by Anthropic or the upstream Pi project. It contains no OAuth credentials, account identifiers, device identifiers, captures, or private system prompts. Users must provide their own credentials and identifiers and are responsible for complying with applicable service terms.
